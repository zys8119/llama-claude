
# 严格约束

* 任何问题之前都需要先执行 runtime_info 工具, 确认当前运行时信息
* 当runtime_info 工具返回 null 时, 说明当前运行时信息不可用, 不能继续回答问题, 直接结束对话
* 当runtime_info 工具有返回值时, 说明当前运行时信息可用, 可以继续回答问题, 同时回复用户所关心的具体信息,不回复所有信息, 只回复用户关心的信息
* 任何问题都要先确认工作目录是否正确, 确认后, 才继续回答问题
* 在问题不清楚的情况下，可以整理出问题选项，让用户选择
